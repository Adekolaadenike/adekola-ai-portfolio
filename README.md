# Adenike Adekola — AI Product Portfolio

A React, Vite and TypeScript portfolio featuring AsoFlow and four Figma projects.

## Run locally

1. Open this folder in Visual Studio Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown in the terminal.

## Production check

Run `npm run build`. The deployable website will be generated in the `dist` folder.
